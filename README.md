# Tic-Tac-Toe-Game

A simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Play against a friend on the same device and enjoy a clean, responsive interface.

## Demo

Open `index.html` in your browser to play the game instantly — no installation required.

## Features
- Classic 3x3 Tic-Tac-Toe grid
- Two-player mode (Player X vs Player O)
- Win, draw, and turn detection
- Restart / reset button to play again

## Built With
- HTML – structure of the game board
- CSS – styling, layout, and responsiveness
- JavaScript – game logic and interactivity
